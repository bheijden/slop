      Using this from a terminal or a coding agent
      
The page and the CLI run the same rule files, so a finding here is a finding there.


# lint files, directories and URLs
slop README.md docs/ -r
slop https://example.com/post

# machine-readable, for an agent to act on
slop --format json docs/ -r

# each finding carries what broke and how to fix it:
# { "file": "docs/intro.md", "line": 42, "col": 7,
#   "rule": "note-that", "set": "wikipedia-ai", "severity": "warn",
#   "match": "It is important to note that",
#   "sentence": "It is important to note that timing matters.",
#   "why":    "Didactic hedging ...",
#   "suggest":"Delete the hedge and state the fact." }

# pick rule sets, drop noisy rules, add your own
slop --select wikipedia-ai --ignore promo docs/ -r
slop --rules rules/house-style.json --select house-style docs/ -r

# check a rule set you are writing (conformance + markup fudging)
slop test-rules rules/house-style.json
