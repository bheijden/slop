prosecheck
Open this page from a script, an agent or a CI job

Everything is in the URL fragment, which browsers never send to a server. The document travels with the link; nothing is uploaded.

# the CLI writes the link for you — the file is gzipped into the fragment
slop check --share docs/intro.md

# or build one yourself
#url=https://example.com/post          fetch and lint a page
#text=<base64url>&kind=md              lint text you encoded
#gz=<base64url of gzip>&kind=html      same, compressed
#rules=https://example.com/house.json  load a rule set over https
#select=wikipedia-ai&ignore=promo      choose rules
#mode=fudge&rules=...                 test a rule set instead

# an agent working in a terminal should use the CLI directly:
slop check --format json -r docs/     # match, sentence, why, suggest
slop fudge rules/house-style.json     # conformance + markup fudging

Source and rule format · rules run in a Web Worker with a 2s timeout, so a rule set fetched from someone else's repo cannot hang this tab.
